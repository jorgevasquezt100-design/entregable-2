Para ejecutar este proyecto, es necesario tener previamente instalado Node.js en el computador. Luego, se debe descargar y abrir el proyecto en Visual Studio Code, abrir una terminal o Command Prompt.

Después, el usuario debe ubicarse en la carpeta raíz del proyecto utilizando la terminal. Una vez dentro de la carpeta, deberá ejecutar el comando npm install o npm i para instalar todas las dependencias necesarias.

Cuando la instalación finalice, se debe ejecutar el comando npm run dev para iniciar el servidor de desarrollo y visualizar el proyecto en el navegador.
